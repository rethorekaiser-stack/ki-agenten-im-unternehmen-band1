# DL-114 Kopiervorlage Skelett, leer und ausgefüllt

## Zweck
Vom KI-Buchhalter zum eigenen Agenten: eine Leervorlage für einen beliebigen Agenten und das ausgefüllte Beispiel, das zeigt, was beim KI-Buchhalter an jeder Stelle steht und welcher Download die Einzelheiten liefert.

## Dateien
- `leervorlage.md` – Skelett eines Agenten in der Reihenfolge des Aufbaus, mit Verweisen auf die Einzelvorlagen DL-102 bis DL-133.
- `beispiel_ki_buchhalter.md` – dasselbe Skelett, ausgefüllt am KI-Buchhalter.

## So gehen Sie vor
1. Leervorlage kopieren und umbenennen.
2. Je Schritt die angegebene Einzelvorlage ausfüllen; das Beispiel zeigt die Tiefe.
3. Feste Regeln des KI-Buchhalters nur übernehmen, wenn sie für Ihre Stelle passen; was nur für die Buchhaltung gilt (Umsatzsteuer, Kontenrahmen, DATEV, Lohn), ersetzen Sie durch Ihr Fachwissen.

## Anpassungshinweis
Das Skelett ist plattformneutral. Wie es auf einer bestimmten Plattform umgesetzt wird, zeigen die Plattformbände.
